Progress tracker for **"100 Days of Code: The Complete Python Pro Bootcamp"** by Angela Yu (Udemy). This monorepo contains daily exercises and projects spanning Python fundamentals through full-stack web development.

## Projects Covered

- **Day 25–44:** Python intermediate — CSV/JSON data handling, APIs, HTML/CSS basics
- **Day 45:** Web scraping with Beautiful Soup
- **Day 48:** Browser automation with Selenium
- **Day 58:** Bootstrap frontend framework
- **Day 59+:** Flask, RESTful APIs, authentication, SQLite, Flask-WTF, CKEditor
- **Standalone:** Quiz game, Turtle racer, data science with Pandas (Jupyter notebooks)

## Tech Stack

Python, Pandas, Jupyter, Selenium, Beautiful Soup, Flask, SQLite, HTML/CSS, Bootstrap

## Structure

```

*.ipynb              → Data science notebooks

```

Each day's folder is self-contained with its own exercises and solutions.
